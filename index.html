07 — FAQ

Common questions.

Quick answers to things clients usually ask before we start a project.

How does the process work?

We start with a short conversation about what you need. Then I share a written scope, a fixed price, and a realistic timeline. Once you approve, I start building. You'll get progress updates at every milestone, and the final delivery includes the deployed site and complete source code.

What technologies do you work with?

On the frontend: HTML, CSS, JavaScript, Tailwind CSS and React. On the backend: Node.js and Express. For data: MongoDB with Mongoose. I also work with Git, REST APIs and modern tooling like Vite. If a project needs something outside this stack, I'll be upfront about it before we start.

Do you offer revisions?

Yes. Every package includes a set number of revision rounds — Starter includes 1, Professional includes 2, and Premium includes 3. Revisions cover refinements to the delivered work, not a change in scope. If you want to add new features mid-project, we'll discuss that separately.

How do we communicate during the project?

Through email, WhatsApp, or any messaging platform you prefer. I send progress updates at each milestone so you always know exactly where the project stands. You can reach me any time during a project — no waiting for a weekly call.

How do I get started?

Fill out the contact form or message me on WhatsApp. Tell me briefly what you're building and what stage it's at. I'll reply with whether I'm a good fit — and if I am, we'll get on a short call to lock down the details.

What's included in the delivery?

The fully deployed website, the complete source code on GitHub (if you want it), and a short handover document explaining how to update content, where things live, and how to deploy new changes. You own everything after delivery.
